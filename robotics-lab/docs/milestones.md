## 마일스톤 0. 커리큘럼 & 공학 명세 확정 (완료)
- **대상 범위**: ESP32 핀 제약, 2축 평면 로봇 팔 FK/IK, HC-SR04 초음파 ToF, 이산 시간 PID 제어 (4개 모듈 + 총 20문항 퀴즈)
- **산출물**: `docs/curriculum-spec.md`, TypeScript 정적 데이터 스키마 (`src/data/`)

## 마일스톤 1. 3D 랩 코어 엔진 & 아이패드 PWA 껍데기 (현재 단계)
- **목표**: 콘텐츠 확장 전에 터치 감도와 시각 완성도가 검증된 3D 뷰포트 + 공통 5탭 껍데기 구축
- **세부 구현**:
  1. `Vite + React + TypeScript + Three.js(R3F) + Tailwind CSS + vite-plugin-pwa` 세팅
  2. 스튜디오 3D 뷰포트: 엔지니어링 그리드, 조명/그림자, 카메라 프리셋(등각/정면/상단/리셋)
  3. 아이패드 터치 & PWA 최적화: `touch-action: none`, `100dvh` 레이아웃, Safe Area 대응, 44px 이상 터치 타겟, 오프라인 매니페스트
  4. 다크 엔지니어링 랩 테마 & 한국어 UI (5개 탭: 개요 · 핀아웃 · 시뮬레이터 · 코드 · 퀴즈)
- **완료 기준 (Gate)**:
  - `npm run build` 타입/번들 오류 0건
  - 아이패드 Safari 및 데스크톱 브라우저에서 3D 캔버스 회전/줌/프리셋 전환, 탭 전환, 퀴즈 풀이가 끊김 없이 동작

## 마일스톤 2. 3D 부품 분해·핀 인스펙터 고도화 (예정)
- **목표**: ESP32, HC-SR04, 서보모터의 정밀 3D 분해 뷰 및 인터랙티브 배선 검증기(3.3V 분압 회로 포함) 구현

## 마일스톤 3. 3종 핵심 시뮬레이터 완주 (예정)
- **목표**:
  - 초음파 레이더 (40kHz 빔 각도 15°, 타임아웃 38ms, 5V→3.3V 레벨 시프트 경고)
  - 2축 로봇 팔 FK/IK (도달 가능 환형 영역 시각화, Elbow-up/down 전환, 특이점 경고)
  - 디지털 PID 제어기 (위치형/증분형, 안티 와인드업, LPF 필터, 실시간 반응 그래프)
